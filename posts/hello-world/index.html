2 Nov 2026 · part of sneakyram.in platform

I’m Ram, a cybersecurity student from Hyderabad. This blog is where I write down what I’m learning and how I build my projects, so I understand them properly and so you can follow along.

You’ll find three kinds of posts here:

  • Build logs for each project, from the first plan to the problems I hit on the way.
  • Notes on security topics I’m studying.
  • Links to write-ups for retired Hack The Box machines, which live on docs.sneakyram.in.

The site itself is the first project: a static blog with a strict Content-Security-Policy, built and checked by GitHub Actions on every push.
